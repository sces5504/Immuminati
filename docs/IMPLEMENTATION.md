# M1 實作與接續指南

> **歷史文件，非現行規格。** 2026-10-17 已改採 [主規格 v2.0](Immuminati-spec.md) 的混合型可暫停 RTS；本檔記錄舊原型，以下容量、數值、實作與測試結論不代表新版需求或已完成。新開工請讀 [交接文件](CLOUD-HANDOFF.md)。

## 交付範圍

M1「莢膜防線」為真正可玩的局部肺部防禦關卡。三區、共用 4 AP、多指令、調理／主動及自動吞噬、調度、增援容量預留與等待、繁殖／擴散、組織損傷、勝敗及保全星等皆接入規則。M2–M6 從首頁可查閱，明確顯示開發中，沒有通關解鎖；不可把入口或百科解讀為五關已完成。

## 啟動

Node 24 與 npm 11 為本次驗證版本。依賴鎖定於 package-lock.json。

```sh
npm ci
npm run dev
```

開啟終端輸出的 `/Immuminati/` URL。預設開發埠 5173。

```sh
npm run verify
npm run preview
```

預覽網址為 `http://localhost:4173/Immuminati/`。瀏覽器驗證另需：

```sh
npx playwright install --with-deps chromium
npm run test:browser
```

瀏覽器腳本會自行啟動 4175 埠的 production preview、操作 UI、更新 `docs/evidence/`。可用 `BASE_URL` 指定已啟動的相同子路徑服務。雲端執行時的 `PLAYWRIGHT_BROWSERS_PATH` 是執行環境選擇，不是遊戲資產路徑。

## 模組邊界

- `domain/model.ts`：具型別的內容、指令、事件、戰鬥、存檔與展示契約。
- `content/game.ts`：M1 數值、連線、初始防線、三種配置、病原特性與可用細胞池；`encyclopedia.ts` 包含全部九種角色、六種病原及機制／來源與簡化範圍。
- `engine/battle.ts`：純引擎；只依賴 domain，內容顯式傳入，沒有 React、DOM、localStorage、全域亂數或真實時間。
- `application/session.ts`：指令提交、回合歷史、結果紀錄、重播本回合指令以撤銷。
- `presentation/CellArt.tsx`：細胞與病原的分層 SVG 素材。`playback.ts` 映射事件、控制展示時鐘；播放器只有展示與完成通知，沒有規則派送回呼。
- `ui/Board.tsx`：normalized anchors、獨立命中區、接觸陰影、待機／動作／選取圖層與 event clips；`ui/App.tsx` 協調操作和播放器。
- `persistence/save.ts`：版本化 Zod 驗證、大小與內容 ID／範圍檢查、回合指令重建一致性、匯出／匯入及儲存錯誤。

新關卡使用既有機制時，新增 ScenarioDefinition／PathogenDefinition 內容即可；引擎與 Board 不辨識 `m1` ID。測試以新增 sample 內容驗證胞內存活、宿主與感染負荷保留，沒有把 sample 包裝成已完成的 M2。新增訊號／呈遞等機制仍需擴充 domain、相應系統、事件映射與驗證，不能只改文案宣稱功能存在。

## 已採數值與時序

每回合 4 AP，移動及調理 1，主動吞噬 2，招募 2。巨噬／嗜中性／樹突的已調理吞噬量為 5／4／1，未調理都是 1；主要作用每回合一次。主動吞噬會占用該次機會，移動與支援不會。

6 次既存特異性抗體／補體局部覆蓋，持續 3 次結算，不能重複標記仍有效群體。標記不直接殺菌；局部新繁殖負荷承接標記，跨區擴散者不承接。這是教學抽象，非抗體產生流程或真實濃度模型。

順序固定為細胞 → 殘餘病原繁殖 → 高負荷擴散 → 損傷 → 等待／到場 → 標記到期 → 勝敗。每個胞外群體每回合 +2，負荷 ≥9 時沿相鄰區擴散 1。每點殘餘感染造成 2 損傷。新到場不參與當次細胞階段。嗜中性球需 1 次結算，巨噬需 2 次；募集占用預留容量，失守目的區保留等待紀錄。

M1 要求所有感染來源清除且三區均存活；任一區失守優先判敗。12 回合未達標失敗。三區等權保全率 ≥85% 三星、≥60% 二星，其餘成功一星；失敗零星。結算後不能補血刷星。數值仍屬首個可玩版本，未經外部玩家平衡研究。

## 權威結果與播放

引擎一次回傳最終權威狀態及含逐事件快照的 frames。application 立即保存穩定結果；展示由行動前快照依序播放，播放回呼只換 visual state。反覆點擊由同步鎖與 disabled 雙重攔截，AP 不由動畫扣除。

跳過同步至既定結果並清理 timer；隱藏頁籤安全快轉展示，不自動推進下一回合；讀檔直接顯示已提交狀態。切回首頁、重試、匯入與卸載清理播放器。百科／設定可在播放時查閱。手機選取會帶到下方指揮面板，下達指令會帶回戰場，確保看得到動作；底部始終保留結束回合／跳過控制。

待機 phase 由穩定 ID 決定，不消耗引擎 RNG。膜、顆粒、核、整體漂浮、選取環及動作使用不同圖層。支援正常、2×、4×、跳過、系統與手動降低動態效果及待機開關。此版無音效。

## 存檔

Key 僅 `immuminati:save:v1`，不清空同 origin 的其他網站資料。schema 1、rules 1.0.0、content m1.1。存檔保存權威狀態、回合起始快照、指令與事件、已讀百科、設定與最佳保全紀錄，續玩仍可撤銷未結算指令。匯入只接受本版且不超過 2 MB；未知版本保留原檔並回報，不宣稱支援尚未存在的遷移。儲存失敗仍可玩並可匯出。

## Pages

`vite.config.ts` 的 base 為 `/Immuminati/`，組織 SVG 由 CSS 相對 import 交由 Vite 處理，favicon 透過 BASE_URL。沒有本機絕對資產路徑、外部字型或執行時服務依賴。

`.github/workflows/pages.yml` 在 PR 執行規則、型別、建置及瀏覽器操作；main 通過後使用 Pages Actions 發布 dist。Repository Settings → Pages 需選擇 GitHub Actions。實際遠端託管狀態與本次執行結果請見 VALIDATION.md；本機子路徑成功不等於遠端 Pages 已上線。
