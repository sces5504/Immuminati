# M1 即時戰術重製：實作與驗證

日期：2026-10-17。需求是使用者試玩後確認的「畫面、操作和玩法一起重做」。玩法修訂見 [TACTICAL-REDESIGN.md](TACTICAL-REDESIGN.md)；舊版驗證不代表新版驗證。

## 已實作

正式入口改為 `src/tactics`：domain 定義狀態／命令／事件，content 放 M1 的地形、單位、三波與數值，engine 負責固定 0.2 秒步進及全部結果，application 管理暫停／部署撤銷，persistence 驗證版本化存檔，presentation 用 Three.js 播放，ui 處理指揮與資訊。

位置、通道、接觸距離及冷卻有實際規則。調理不直接殺菌；吞噬後胞內存活與清除分支不同。三波全清且三區存活才勝利，損傷、容量預約、等待到場、時間上限、保全星等均有權威結算。暫停可下多令／撤銷；跑動後不可回溯。隱藏頁籤自動暫停，不追算離線時間。正常與加速排程消耗相同固定步數就得到相同狀態及事件。

新存檔 key 為 `immuminati:tactics:v2`，舊 `immuminati:save:v1` 不覆寫。最多保留 10 個暫停部署快照；匯入上限 2 MB，驗證 ID、型別、容量、感染來源、進度及結算一致性。損壞匯入不覆寫目前進度。舊版回合規則無法直接轉為新局。

## 美術及動作

本版地形、細胞、菌群、莢膜、囊泡、抗體標記均由本專案原創程序幾何／材質組成，不使用 ImmuneQuest 角色或截圖。組織地面與起伏、肺泡邊界、血管、細胞及菌群分層渲染。菌負荷以雙球對的密度表達，上限 50 對，UI 保留權威總負荷。

每個細胞有不同相位的呼吸、漂浮、膜及突起變化。移動依引擎位置和路徑平滑，選取有獨立環／路徑；調理有 Y 標記附著；增援經入口出現並走向目的地；吞噬有兩側偽足伸展／合攏及目標向胞內移動，清除縮小消失，存活保留金色囊泡與活菌。傷害改變組織色澤，結算有星等與結果面板。降低動態會抑制局部動畫，不改規則。

目前是完整可操作的原創幾何美術版本；精緻雕刻模型、貼圖、音效、專業角色動作仍可提升。沒有使用尚未取得的外部正式美術包；未將概念圖宣稱為可拆分素材。WebGL 為必要條件，無法建立時顯示明確訊息。SwiftShader 降低渲染解析度與陰影貼圖，避免軟體渲染壓力；不降低規則精度。

## 實際驗證

- `npm run verify`：31 項測試、TypeScript 與 Vite production 建置通過。16 項新戰術測試加 15 項保留的舊規則測試；舊測試不作新版通關依據。
- 新戰術測試含：非法命令不變更、調理重複輸入、接觸距離、冷卻、到場時間、容量、未來波／胞內來源不誤勝、失敗優先、星等門檻、三配置 × 兩種實際策略通關、確定性、範圍不變條件、移動投影、暫停／撤銷、存檔／壞檔、最後一波結算存讀，以及視覺設定不影響權威結果。
- 瀏覽器完整驗證與部署結果：完成後補記，下方機器結果檔為實際依據。
- `npm run test:animation`：Chromium 141 / SwiftShader 通過清除與胞內存活的抽象 fixture，留下錄影與截圖。fixture 是展示契約驗證，不能當作 M2 已完成，也不表示本案例肺炎鏈球菌會胞內存活。

證據位於 [evidence/tactics](evidence/tactics)：`browser-results.json`、`animation-results.json`、桌面／手機截圖及 `.webm`。完整實戰錄影包含待機、調度、吞噬、增援與三波結算。

## 限制與接續

- M2–M6 僅入口、情境說明及百科，全部可查看且標示開發中；尚無其專用戰鬥規則，不宣稱六關可玩。
- 新增既有機制的關卡可建立 TacticalContent 並登錄；新病原字形、特殊免疫機制及新結局仍需擴充對應引擎／展示契約。沒有宣稱所有五種未完成機制都能只填資料。
- 行走使用三防區通道導航，不是任意立體網格尋路；目前單位不做物理碰撞，距離及容量仍有權威限制。比例、菌負荷與時間為教學抽象。
- 目前沒有音效。柔光與形態仍可繼續打磨，尚無 ImmuneQuest 商業成品的精細程度。
- 實際測試為桌面 Chromium 與 360×800 直向觸控模擬；尚未測實體手機、Safari、Firefox、長時間低階硬體效能及讀屏器。不能把模擬裝置稱作真機。
