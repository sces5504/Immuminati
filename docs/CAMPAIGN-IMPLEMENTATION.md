## 架構與規則

`domain` 保存權威狀態；`content/campaign.ts` 配置病原、波次、器官、開場細胞、目標與機制類型；`engine/infection.ts` 提供共用感染與組織機制，整合到原本 `simulation.ts` 固定 0.2 秒步進；`immunity.ts` 處理訊號／呈遞／效應。控制器、展示與存檔維持分離。新增沿用機制的情境主要修改內容資料；新生物機制仍需要引擎與展示擴充。

| 關卡 | 組織與目標 | 實際機制 |
|---|---|---|
| M1 肺炎鏈球菌 | 肺泡，三波來源清除 | 莢膜／C3b、Fc 調理、包覆吞入、延遲吞噬體殺菌 |
| M2 Typhimurium | 腸黏膜與局部巨噬感染，清除來源 | 巨噬含菌囊泡持續存活，欠缺 IFN-γ 時增長及再播散；Th1 支援囊泡內清除 |
| M3 結核 | 肺部片段，控制感染 | 感染巨噬＋相鄰活化 Th1／IFN-γ 建立圍堵；負荷 ≤25、感染防區圍堵 ≥60%、各區保全 ≥45%，維持20秒。活菌可保留，不要求全清／不表示治癒 |
| M4 流感 A | 肺泡上皮，清除胞外與產毒來源 | 胞外病毒不繁殖；易感上皮感染建立→核內複製材料→產毒釋出；IFN-I 降低易感與產量；NK 條件殺傷、DC MHC-I 交叉呈遞→CD8 活化與配對；胞外抗體中和 |
| M5 念珠菌 | 口腔黏膜，限制侵襲並清除 | 出芽酵母／分枝菌絲；菌絲不可整條吞入，嗜中性球接觸顆粒作用；Th17／ILC3 的 IL-17／IL-22 經上皮提高抗菌肽、屏障與趨化 |
| M6 HIV | 淋巴組織，維持局部免疫支援 | CD4 易感宿主、感染建立、核內整合、產毒／潛伏分開；特異 CD8 無法攻擊不表達病毒肽的潛伏來源；功能性 CD4 下降減慢活化、降低 IFN-γ 並限制新 T–B 幫助 |

M6 為未治療的有限觀察情境，不給一般勝利或星等。控制行為影響局部負荷及支援時間；CD4 功能不足或觀察期限才產生 `limited` 結果，沒有最後一刻清場。長壽命潛伏來源可在整個短觀察期不再活化，其他來源可週期再活化。這是規則抽象，不代表每個潛伏細胞必然永不活化。功能障礙連續累積，非臨床疾病時間預測。

初次關卡入口不揭露必然結局；`revealed` 只在結果實際可見且完成兩個畫面影格後，由 UI 呼叫確認方法。純引擎、略過動畫、檔案匯入不會直接解鎖結局解釋。匯入時只保留本機先前已揭露清單。結果畫面說明潛伏與免疫限制，也明確說明現實 ART 可以有效控制 HIV。

## T–B 協作與查證

蛋白抗原反應不是「T helper 必須回肺泡腔」。DC 在引流淋巴組織啟動 CD4；B 結合抗原並呈遞同源來源肽／MHC-II，接受近距離 T 幫助（CD40L／CD40、細胞激素），再分化。這裡用結內抽象互動與接觸動畫表現，沒有新增第二套地圖操作。

引擎要求同源抗原、活化的適合 helper／Tfh、淋巴結位置與近距離接觸，維持3模擬秒後才開始10秒分化；移開或不相符會中斷未完成對接。Th1／Th17 不充當本模型的 Tfh；保留既有一般 helperT 的混合支援角色以相容舊局。T 非依賴多醣反應確實存在，本版明示未模擬，不將所有 B 反應套成 T 依賴。

## 展示契約與素材

`MolecularModels.ts` 提供可替換的獨立 Y 形抗體及三葉 C3b 模型；抗體綠、C3b 黃，並用形狀與文字區分。抗體定向移近、補體高弧灑落，分子抵達後才顯示附著；引擎先結算，動畫只讀事件。1×、2×、略過、降低動態不重複計算／扣點。附著不是吞入，更不是胞內殺菌；病毒中和僅限胞外。

程序素材沿用柔光材質：雙球菌、桿菌、細長抗酸桿菌、帶表面突起病毒、出芽酵母及分枝菌絲有各自幾何。原細胞膜、分葉核、偽足、顆粒、漿細胞粗 ER 保留，Th1／Tfh／Th17／ILC3 加入不同數量表面受體；pDC 使用分枝膜。各單位相位不同，原吞噬包覆、吞入及胞內結果動作保留。

肺泡薄隔與血管、腸絨毛／刷狀緣、口腔扁平上皮、淋巴網狀基質與 CD4 宿主分別建模。核內剖視線段表示病毒基因組，不畫成完整成熟病毒。圍堵纖維表示組織組織化程度，不虛構可操作免疫單位。

尚未使用外部高精度美術資產；本版均為可替換程序模型，不是圖像熱區或佔位球。未建完整胚中心、親和力成熟、多重表位、HLA 多型性、病毒突變、每個受體、全身免疫與器官修復；CD4 功能為群體數值，機制濃度為防區聚合而非完整擴散。
