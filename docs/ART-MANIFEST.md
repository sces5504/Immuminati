## 圖層

組織 → 相鄰連線 → 區域膜／長期損傷 → 容量預留 → 接觸陰影 → 獨立細胞／病原 → 作用特效 → 選取／負荷／狀態 → UI。每個單位的點按框固定，漂浮只發生在其內部容器。位移／選取／待機 transform 不互相覆寫。角色圖不含文字。

## 事件映射與實際表演

`src/presentation/playback.ts` 的 eventMap 為完整映射，`src/ui/Board.tsx` 與 `src/styles/main.css` 實現 clip：

| 事件 | 表演 |
| --- | --- |
| 選取 | 穩定輪廓＋短選取環，保留其他單位待機 |
| UnitMoved | 沿相鄰區域連線的位移、加減速、輕微形變，停在新錨點 |
| PathogenEngulfed | 吞噬者接近 → 左右偽足伸展、包覆 → 目標向囊泡內移／縮小 |
| PathogenCleared | 已吞入來源縮退消化，不保留胞內活菌標記 |
| IntracellularSurvival | 保留囊泡內負荷、宿主內雙球測試字形與「胞內存活」標記 |
| OpsoninApplied | 抗體 Y／補體圓標記向目標附著，保留調理有效時間，無傷害表演 |
| OpsoninExpired | 標記移除及事件說明；沒有假清除動畫 |
| RecruitmentRequested | 虛線預留位置與募集過渡、右側等待佇列 |
| RecruitmentWaiting | 等待數更新及原因，不偽造抵達 |
| UnitArrived | 由血液方向進入、落到區域、恢復待機 |
| PathogenReplicated | 獨立雙球體伸展／分離，再更新群體負荷 |
| PathogenSpread | 一負荷沿相鄰連線移動，不攜帶局部調理標記 |
| TissueDamaged | 僅對相應區域收暗與持續受損色層，保留健康條 |
| PriorityChanged／PriorityFallback | 目標／原因資訊切換，不假裝攻擊 |
| TurnEnded／BattleEnded | 防線重整或結果浮層，接續正確資源與結算 |

主要行動在正常速度約 0.6–1.5 秒；吞噬包覆約 1.5 秒。待機週期約 3.8–5.7 秒，以穩定 ID 產生不同相位；整體漂浮、膜形變、核與顆粒相對移動均可見。無引擎亂數消耗或每幀 React 狀態／存檔寫入。

## 分支驗證

M1 肺炎鏈球菌的引擎結果是清除，不為展示而偽造胞內存活。開發模式 `http://localhost:5173/Immuminati/#animation-lab` 提供抽象展示契約樣本，從純引擎產生清除／存活事件並播放同一套 Board；此入口會從 production build 排除。

`npm run test:animation` 檢查包覆中 CSS path 確實改變，並驗證清除不留下胞內標記、存活保留囊泡內 3 負荷與宿主標記。測試字形不是正式沙門氏菌素材，也不代表 M2 已完成。短錄影與截圖見 evidence。
