[公開遊玩](https://sces5504.github.io/Immuminati/) · [動作／素材預覽](https://sces5504.github.io/Immuminati/#visual-lab) · [美術替換交接](RTS-ART-HANDOFF.md)

## 實作決策

- Node 24.19.0／npm 11.9.0；TypeScript、Vite、React。`domain/content/engine/application/presentation/ui/persistence` 各有獨立目錄。新增關卡沿用機制可只換 Scenario；測試用不同初始感染灶及零訊號配置驗證。
- 引擎純邏輯、0.2 秒固定步進、LCG RNG 與步號指令。每步：提交指令→場／內皮→淋巴結→募集→AI／接觸→來源／繁殖→損傷／資源→目標。失敗優先於同一步勝利；未來來源或胞內活菌均阻止誤勝。
- SVG 2.5D 分層佔位，不依賴舊 Three 模型。獨立細胞膜／核／局部動態、莢膜雙球菌、表面調理、接觸／包覆／囊泡／分解或存活、血管到場、訊號與遷移均已實作。沒有把概念圖當遊戲背景。
- 組織為開放連通平面，路徑是可通行邊界內的連續直線；沒有內部障礙繞路或自由旋轉。一般細胞不能直接調度進血管，募集由專用跨內皮流程進入。沒有區域格位、容量預約、每區 3 或全場 7 限制。
- CXCL8 25×17 擴散／衰減場，細胞辨識後形成來源，嗜中性球採樣梯度。發炎是 TNF／IL-1 相關作用的合併模型，分開影響內皮與過炎傷害；不是訊號傷害法術。
- M1 初次追蹤抗原為 `spn:surface-protein-A`（教學用暴露蛋白靶標抽象，未聲稱是一個臨床疫苗）。DC 攝取、成熟、遷移、T 活化、B 辨識／協助、分化與抗體交通分開。早期補體與新生特異性抗體分開；不把莢膜普通多醣交給泛用 DC→T→B 路徑。
- 暫停可多指令規劃、資源／供應預留與逐條撤銷；恢復依序驗證。提交後募集供應已投入、不可退款；規劃撤銷無消耗。手動與 AI 使用同一細胞攝入／冷卻機會；ID 去重。背景與遮擋面板安全暫停，不追算離線時間。
- 存檔 schema 3 與 `immuminati:rts:v3` 獨立；保留舊兩個 key。Zod 驗格式、版本、數值、ID、宿主／囊泡、淋巴結、規劃、結果與時鐘一致性，8 MB 上限；驗證成功且本機寫入成功才替換現局。

## 實際驗證

- `npm run verify`：17 個新 RTS 測試、TypeScript 與 production build 通過。未將舊測試當作新規格證據。
- 規則：合法／非法／重複指令、暫停／撤銷、內皮條件／延遲募集、AI、擴散與趨化、病原分群、莢膜／調理、攝入與存活、宿主死亡釋回活菌、淋巴特異性／階段、組織損傷／星等／同一步優先序。
- 相同種子／指令／600 步，1×／2×／4× × 正常／略過／降低動態，完整狀態與事件完全相等。全局無動畫回呼提交規則。每 10 步存檔還原再推一步，和未中斷局一致。
- 30 群同熱區規則測試：可接觸及清除，不會因舊名額拒絕。瀏覽器另以明示受控的 30 群 fixture 驗證名單選取與實際接觸。
- 動作驗證：[animation-results.json](evidence/rts/animation-results.json)，正常／降低／略過的同一步狀態相等；切換替換 provider 前後權威 JSON 相等；獨立膜待機 >5 秒，包覆／吞入／清除與受控胞內存活分支均驗證。
- 本機完整操作通過，見 [browser-results.json](evidence/rts/browser-results.json)：桌面與 360px 觸控模擬各 7 項檢查。兩者組織 80.180%／80.132%、三星；無 console 錯誤或資產 404。公開 Pages 結果待實際發布後補記。

瀏覽器為 headless Chromium 154.0.8037.57，桌面 1440×1000，手機 360×800 的觸控模擬；地圖拖曳使用真實 CDP touch 事件，位置指令使用 touchscreen tap。其他介面亦經 Playwright 實際點按。不是實體手機，也未涵蓋 Safari／iOS。額外檢查見 [extra-results.json](evidence/rts/extra-results.json)：44px 目標、鍵盤焦點／Escape、降低動態、選關百科保留續玩。headless 沒有提供真實 hidden 頁籤狀態；背景安全暫停以受控 visibility 事件驗證，真實 OS 背景切換仍待實機複驗。

動作 lab 1280×1000 的量測（錄影與其他檢查同時進行，CPU／SVG 軟體繪圖環境）：1× 139 幀／2.516s，p50 16.7ms、p95 33.3ms；4× 59 幀／2.538s，p50 33.3ms、p95 83.3ms。約 55／23 FPS，沒有把這個結果宣稱為實體手機 30 FPS 或桌面穩定 60 FPS。4× 增加固定規則步，不跳規則；實際呈現速度受裝置負載限制。

## 發現並修正

- 桌面／觸控鏡頭共用螢幕空間平移，超過 7px 拖曳門檻後不下位置指令。每次縮放後重測正反方向。
- 捕捉 pointer 後以實際畫面命中查詢選取，避免 capture 讓目標永遠變成 SVG 根節點。密集重疊時保留名單入口。
- 手機改為較近的初始鏡頭；選位置模式帶回地圖。測試等待版面定位後才 tap，避免點舊捲動座標。
- CSS `input` 規則曾覆蓋 hidden，已補 `[hidden]`；存檔檔案選擇器不常駐佔畫面。
- 開啟選關百科／設定保留既有局，不以新局覆寫續玩；載入安全暫停。無效匯入保留現局與原存檔。
- 每個動作階段的存讀以權威進度還原；嗜中性球壽命結束釋回尚活的胞內病原，避免永遠卡住。
- 測試改用狀態條件等候募集到場，避免錄影環境負載改變實際 wall time 時誤判。

## 限制與下一階段

M2–M6 只有開發中入口與百科，未實作其關卡；受控存活不是 M2 完成證據。M6 敘事結局／揭露尚未實作。沒有音效、自由旋轉、捏合、真實流體或障礙繞路；提供按鈕縮放與開放連通組織平面。細胞／病原是群體抽象，並非人體規模。

精緻 C 畫質、連續體積膜材質、更自然肺泡／偽足、LOD 與實體手機效能待後續精修與驗收；詳細素材 API、來源、錨點、動作契約及逐項待辦見 [美術接手](RTS-ART-HANDOFF.md)。不需為替換素材改引擎、AI、平衡或存檔。
