## 2. 玩家體驗與核心循環

對象為具基礎生物知識的醫藥／生命科學大學生；背景較少者也能藉情境提示與百科遊玩。遊戲性優先，但理解免疫機制應能改善決策。

核心循環：觀察感染與細胞意圖 → 暫停判斷原因 → 安排防守位置、募集、調理與反應政策 → 恢復時間，觀看多條反應同時進行 → 由因果紀錄調整策略。

玩家主要判斷：哪個感染灶需要支援？莢膜是否讓未調理吞噬效率不足？趨化訊號能否把增援帶到現場？該先維持先天防線，還是投資較慢的淋巴結支援？目前發炎是在控制感染，還是在犧牲組織？

單位代表一群同類細胞／病原，不逐顆模擬人體規模。群體數量、可視代表數與剩餘作用能力應有一致抽象；畫面少畫幾個物件不能改變權威負荷。

## 3. 時鐘、暫停與指令

- 使用固定步進的模擬時鐘。1×／2×／4× 改變每秒執行的步數，不放大單步、不跳過病原繁殖或作用機會。固定步長可先採 0.2 模擬秒，再依誤差與效能調整。
- 移動、偵測、吞噬、繁殖、訊號擴散／衰減、募集、組織變化、資源恢復與淋巴結流程依同一權威時鐘推進；並行是遊戲設計，不依賴各動畫各自計時。
- 暫停時上述程序全部凍結，不能靠停留真實時間恢復資源或縮短適應性等待；純視覺待機可保持輕微生命感，並標示「模擬已暫停」。
- 暫停時下達指令進入規劃佇列，顯示預計成本、前置條件與到場時間，可逐條撤銷。恢復時按穩定順序驗證並提交；規劃用資源保留不等於區域名額。被拒指令不扣資源，說明原因。
- 運行中同樣能下令，於下一個規則步處理。不為等待影片而全局鎖住操作；個別細胞的攝入／移動／冷卻階段可依規則限制該細胞。
- 指令具有唯一 ID；雙擊、重送、動畫完成回呼與重繪都不得再次扣資源或執行作用。相同細胞的手動與自主行為共用冷卻與作用機會。
- 已推進的生理結果不能靠撤銷回溯。背景頁籤自動暫停，回來由玩家恢復；不追算離線感染或累積追趕步數。
- 「略過動作」只壓縮／省略視覺過程；不快轉模擬或跳過階段。「4×」才是加速模擬，兩者須清楚分開。
- 先天、遷移、初次適應性反應有不同相對延遲。關卡將現實時間壓縮為教學時間，UI 說明不代表臨床時數；不能讓新生抗原特異性抗體在按一下後立即出現。

## 4. 連續戰場與操作

### 4.1 空間與密集單位

M1 為肺部局部組織：呼吸道侵入口、感染組織、微血管及通往引流淋巴結的出口。可標示 A／B／C 等解剖分區，但不將分區作為戰鬥格位。單位有連續座標、合法移動地形、作用距離、偵測範圍與路徑。

- 不存在「同區已滿」「預留第幾格」「本區最多幾個細胞」。募集目的地有很多細胞時仍能合法到場；調度不需要另一區空出名額。
- 單位可有局部避讓與視覺散開；不能因避讓永遠無法進入熱區或接觸病原。必要時允許群體重疊／聚合顯示，或在群體間分配作用點。
- 招募受明示的供應與到場程序限制，不硬套舊版全場 7 單位。技術物件預算用聚合、LOD、instancing 或代表數處理；不能偷偷變成玩法中的區域或全場格位限制。
- 密集處能循環選取、使用單位清單或群組篩選；手機不必在重疊小點中碰運氣。群組數與真實負荷可查，選取與命中區跟隨畫面位置。

### 4.2 鏡頭與手勢方向（必須修正）

採「抓住地圖」的螢幕空間操作：拖曳向右，地形／單位／訊號覆層一起向右；拖曳向上，地圖也向上。引擎內相機座標可能朝相反方向變化，不能因此反轉玩家看見的結果。

- 桌面拖曳與手機單指拖曳同方向；提供縮放、重設及觸控可用的按鈕。捏合縮放可加，但不能是唯一縮放途徑。
- 固定斜視角＋平移／縮放是必要範圍；自由旋轉非必要。若保留旋轉，旋轉後仍遵守同一螢幕拖曳方向，不依世界 X／Z 軸硬映射。
- 點選、拖曳、指定移動分開判定；超過拖曳門檻後放手不得誤下移動／攻擊指令。手機提供明確的「移動到此」等模式與取消鍵，不依賴右鍵或 hover。
- 相機更新後立刻同步投影、拾取與覆層；操作相機不改單位的邏輯位置、目標或亂數。
- 驗證：未碰到邊界時，拖曳 `(＋80, ＋40)` CSS px，固定地標的畫面投影也約移動 `(＋80, ＋40)`；反向拖曳能返回。同測縮放前後、桌面與觸控；若有旋轉，測 0／90／180／270 度。邊界夾限須可理解，不能用它掩蓋反向錯誤。

## 5. 自主細胞 AI 與玩家指揮

基本優先序：有效的玩家指定命令 → 區域／群組政策 → 細胞本能。命令失效時顯示原因並回到合法自主行為，不原地永久發呆。鎖定目標、重選延遲與路徑穩定性需避免單位在兩個感染灶間抖動。

| 細胞              | 自主行為與條件                                                           | 玩家可影響                                                                               |
| ----------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| 巨噬細胞          | 組織巡邏、偵測適當病原、接近與吞噬、辨識後發出局部訊號；攝入與清除分開。 | 防守位置、優先病原、活化政策、短期直接調度；不能因沒點吞噬就完全不作用。                 |
| 嗜中性球          | 合法募集後到場，沿相關趨化訊號前進，接觸適合的胞外目標後自主作用。       | 支援感染灶、優先目標、募集強度；不是無限壽命的固定砲塔。                                 |
| 樹突細胞          | 攝取抗原後成熟、遷移至引流淋巴結，啟動適當呈遞流程。                     | 決定何時優先送出攜帶抗原的單位；流程需符合條件，不能把未捕捉抗原的 DC 當作立即抗體按鈕。 |
| NK（後續關卡）    | 巡邏並依適當異常宿主訊號辨識部分目標。                                   | 巡邏範圍、優先目標；不自動殺掉所有帶病毒細胞。                                           |
| CD8 T（後續關卡） | 經活化、分化與交通延遲後，尋找呈現相應抗原的感染宿主。                   | 部署與優先目標；特異性及呈遞條件不可省略。                                               |
| B／漿細胞         | 依抗原辨識及該路徑所需支援活化、分化，產生具指定作用的抗體。             | 支援適當反應路徑；不在戰場發射泛用殺傷子彈。                                             |

狀態面板能回答「正在做什麼、為什麼選這個目標、還缺什麼」。至少能看見巡邏、趨化、接近、攝入、處理中、冷卻、攜抗原、遷移與等待支援的差異。玩家指定不會賦予不符合生物條件的能力。

## 6. 訊號場是核心系統

訊號改變細胞狀態、移動與組織環境，不是範圍傷害魔法。內容資料定義來源、觸發條件、接收者、擴散／衰減、作用與飽和；同一訊號加倍不必線性加倍效益。

| 訊號／媒介             | 生物作用與遊戲因果                                                                     | 交付範圍                                                                          |
| ---------------------- | -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| CXCL8（IL-8）          | 辨識感染後在局部形成訊號梯度，影響嗜中性球趨化；募集還需要血管與內皮條件。不是傷害波。 | M1 實作。                                                                         |
| TNF／IL-1 相關發炎作用 | 促進局部內皮活化與募集環境；適度反應有益，過度／持續反應增加組織代價。                 | M1 可用具名的「內皮活化／發炎」合併模型，百科說明簡化；不可把所有功能歸給 CXCL8。 |
| IFN-γ                  | 在合適情境提升巨噬細胞的特定抗微生物功能；不能自動解決所有胞內感染。                   | 為 M2／M3 保留契約，M1 不必假裝已有完整 Th1 系統。                                |
| IL-17                  | 透過組織細胞促進相關募集與防禦，口腔黏膜亦含上皮／抗菌反應。                           | M5 實作；不是 Th17 直接射殺真菌。                                                 |
| Type I IFN             | 在病毒情境誘導抗病毒狀態，改變宿主易感性／複製條件。                                   | M4 等適當內容實作；不作 M1 通用殺菌技能。                                         |

玩家透過募集／反應政策影響來源與環境；不能從任意地面憑空施放訊號傷害。M1 訊號視圖必須來自實際模擬場：顯示圖例、來源、分布強弱、接收細胞及當前效果。可切換正常／訊號視圖，選取與命令保持可用，不能用隨機光粒冒充梯度。訊號邊界平滑、不掩蓋病原或細胞。

建議先用低解析網格進行擴散＋衰減，空間索引採樣；訊號更新可比移動低頻，但依模擬步數排程。精細流體、分子級擴散與數百萬細胞不屬本次範圍。

## 7. 募集、資源與發炎取捨

- 反應資源是局內指揮／支援的抽象，不稱回合 AP。恢復、成本、募集池與補給都寫入內容資料並明示。暫停不補充。
- 合法募集至少經過：選擇細胞與支援位置 → 驗證供應／成本／血管條件 → 等待動員與跨內皮 → 從血管入口到場 → 自主趨化或執行支援命令。不能在目的地直接瞬移。
- 部分募集可以先排隊等待內皮條件；UI 明示尚未啟動、等待、已出發與已到場，取消政策及退款規則一致。沒有目的地容量預留。
- 促進募集改變供應速率／內皮與相關反應，不無條件生成任意數量單位。可有可見的生物供應量與恢復速率；不要以「同區最多 N 隻」平衡。
- 組織傷害區分病原損傷、持續過度發炎與適用機制的旁觀者損傷，保留原因。不是每次吞噬都固定扣組織。
- 適度發炎支援控制感染；抑制反應太早可能降低募集／防禦，過度募集也有代價。調節政策影響反應強度，不是免費回血技能。
- 組織保全、發炎與感染負荷分開顯示；降低發炎不等於清除病原。恢復條件與速率資料化，不能掩蓋失守。

## 8. 引流淋巴結：連動流程面板

感染組織是主要戰場；引流淋巴結先做可互動流程面板，不再建立一張需要同時微操的完整 RTS 地圖。

1. 組織 DC 攝取指定抗原，顯示抗原來源與類別。
2. DC 成熟並遷移；此時離開局部防線，保留交通延遲。
3. 淋巴結呈遞與必要共刺激，啟動相應初始 T 細胞反應。
4. 合適的 B 細胞辨識抗原，取得該路徑所需協助，經增殖／分化延遲。
5. 效應或抗體產物依特異性與交通條件支援感染組織；抗體可促進調理，後續仍需效應清除。

面板顯示目前階段、缺少條件、剩餘模擬時間、產物作用與返回組織的方式。資源支援可影響合理的準備／供應條件，不能按一下略過生物階段。初次適應性支援明顯晚於先天反應，時間壓縮在提示與百科說明。

**M1 的抗原背景必須一致：** 採「對本次追蹤的蛋白抗原尚未建立特異性記憶」的局部教學案例。早期可用的補體／有限既存調理背景需與新生抗體分開標示；不能把一開始的調理按鈕寫成已完成新生 B 反應。

M1 必做的一條淋巴結支援路徑，為明確標示的蛋白抗原 T 依賴反應及其可作用於暴露靶標的調理抗體；抗原 ID、抗體靶標及效果相符。**不把這條路徑描述為產生所有抗莢膜抗體的唯一機制。** 莢膜多醣可有 T 非依賴反應；若實作者改採莢膜抗原，必須相應建模，不能讓 DC 向 T 細胞直接呈遞普通多醣來完成泛用 T→B 流程。M1 不必同時實作所有 B 反應分支。[B1][B3][B10]

## 9. M1「肺炎鏈球菌」完整切片

### 9.1 開局與同時進行的反應

- 少量具莢膜的肺炎鏈球菌突破局部呼吸道屏障；已存在組織巨噬細胞與可攝取抗原的 DC，有限先天防線可立即自主反應。
- 巨噬細胞偵測、接近並嘗試吞噬；莢膜降低未充分調理時的攝入效率。UI 能解釋低效原因，不把莢膜做成絕對免疫護盾。
- 辨識後產生局部發炎／CXCL8 相關訊號，內皮逐步活化；嗜中性球經募集與到場延遲，沿訊號前往感染灶。
- 病原持續繁殖、沿通路擴散並傷害組織；免疫細胞移動與攝入、訊號衰減、增援、淋巴結準備和組織變化同時進行。
- 調理提高後續吞噬作用；補體與抗體來源不同，不能把調理標記當作直接減少負荷。不能假定補體終末裂解能像對某些革蘭陰性菌一樣普遍清掉肺炎鏈球菌。
- 病原短時間增加稱繁殖／擴散；本里程碑不承諾即時演化或任意突變科技樹。

### 9.2 玩家必須能做的事

1. 選取單位／群組，調度到連續位置、指派合法目標，或恢復自主行為。
2. 針對感染灶配置有限調理支援，並看見攝入效率與原因的變化。
3. 調整募集優先與目的位置，觀察內皮、等待、到場及趨化。
4. 開關訊號視圖，觀察訊號來源及細胞反應；不需要每隻嗜中性球手動點擊。
5. 優先派出已攜抗原 DC，查看並支援淋巴結流程，等待正確的適應性產物。
6. 管理發炎強度，評估防禦效益與組織傷害；暫停時能理解後再操作。

### 9.3 目標、節奏與平衡

- 明示感染來源與目標。勝利為完成本局感染來源控制、清除本案例可作用的活躍病原，且必要組織仍存活；不能忽略仍在胞內的活病原或已排程的感染來源而誤勝。
- 失敗來自明示的組織／功能崩潰條件；若採有限時間，需說明未達成的目標與結束原因。時間、波次及閾值屬內容資料，不強制沿用舊三波／180 秒。
- 先天防線能爭取時間；至少驗證兩條不同合法策略，例如偏重早期調理／先天控制，或穩住防線等待淋巴結支援。適應性路徑必須實際可到達且有用，不強迫每次通關都等待它完成。
- 以數分鐘的可理解關卡為試玩起點，允許暫停與速度調整；具體成本、數量與階段秒數由首次切片平衡，寫在內容與檢查紀錄，不能宣稱未試玩的數值已定案。
- 結算分開呈現感染控制、組織保全、發炎代價、策略因果及一／二／三星；星等依組織保全，門檻在內容資料顯示。局內熟練與知識有用，局外沒有永久戰力／裝備。

### 10.1 HIV 敘事與結果契約

- HIV 與 Candida 為獨立關卡；HIV 是病毒，AIDS 是疾病階段，不能以 Candida 機會性感染替代 HIV 玩法。
- 可感染宿主需符合條件，不能讓所有 T 細胞都等同易感 CD4。生產性感染、潛伏來源與免疫功能分開；CD8 不能直接看見所有潛伏感染。
- 局部控制、功能保存及支撐時間受玩家策略影響。有限情境於防線崩潰或敘事終點結束；不在最後一刻無條件殺光細胞，不製造永不結束的假勝利目標。
- 使用特殊結束結果，不走一般勝利或通關星等。首次入口／說明不以「必敗」「特殊模式」、空星槽等劇透；百科仍可查正常生物資訊。
- 結局說明這是受限教學案例，不代表所有 HIV 感染者的必然病程；明示現代抗反轉錄病毒治療可有效控制感染，讓人長期健康生活。
- 只有實際呈現結局文字後才記錄「已揭露」。存讀、退出、匯入匯出或略過動畫不能提前揭露或遺失揭露紀錄。

## 11. 美術、動作與因果展示

正式美術方向仍是 [C 參考圖](art-direction/c-soft-micro-3d.png)：柔光、半透明膜、可辨識內部形態、自然組織深度。**參考圖上的回合、AP、區域 UI 與 End turn 是舊概念，不能沿用為 RTS 規則。**

分兩階段交付：

1. **玩法 agent：可玩佔位版 M1。** 使用低複雜度幾何、簡單材質與分層結構即可；優先完成玩法、效能、操作、必要動畫及可替換介面。不投入精雕、寫實貼圖或高成本光照，不等待美術 agent 才繼續或發布。需能分辨細胞類型、病原與重要狀態；可搭配輪廓、標記和文字。
2. **後續美術 agent：C 風格精修。** 依 [最終美術條件](art-direction/C-art-and-animation.md) 改善膜、核、偽足、材質與自然組織，沿既定素材／動作契約替換。精修外觀另驗收，不把第一階段的模型宣稱為最終 C 品質。

第一階段可明確交付「可玩 M1（簡單佔位美術，待後續替換）」。以下動作語義在兩階段均保留；第一階段允許簡化幾何與表演細節，但接觸、包覆、吞入及清除／存活必須看得懂，不能刪掉動作。

- 待機：不同單位相位的輕微漂浮、呼吸、膜或偽足局部變化；不移動邏輯座標。
- 移動：朝向與形變、接觸組織、自然過渡；相同群組不整齊同步彈跳。
- 吞噬：接近 → 接觸 → 偽足連續包覆 → 吞入囊泡 → 清除或胞內存活的不同結果。M1 展示正常清除，模組以測試場景證明存活分支，不能說吞入就是殺死。
- 調理：在病原表面附著，與後續吞噬分開；不是直接爆炸。訊號來源／擴散、內皮活化、跨內皮到場、DC 遷移與淋巴結階段有不同表現。
- 組織受損與恢復、感染擴散、勝敗及星等有對應變化。必要文字補充因果，不能讓通用閃光／冒數字代替所有動作。
- 規則先產生權威結果與有序事件，展示再表演。可用動作起始／完成事件與短暫展示殘影處理已清除目標；殘影不再可選或參與規則。動作打斷、重疊與佇列不能讓單位回跳或重複結算。
- 降低動態與略過模式保留明確狀態、目標與結果；不改傷害、時間、資源、亂數或勝敗。

## 12. UI、百科、紀錄與手機

- 戰場佔主要視野，常駐顯示暫停／速度、感染壓力、組織保全、發炎、支援資源及重要等待。移除「回合」「剩餘 AP」「本區 3/3」等舊欄位。
- 桌面可側欄，手機優先直向，下方提供選取／政策／命令；360 CSS px 寬仍可完成所有主要流程，不依靠 hover、右鍵、框選或鍵盤。
- 主要操作目標至少 44×44 CSS px；小細胞可透過放大命中、群組選取與列表操作，不能讓透明命中區遮掉鄰近目標。支援鍵盤焦點、文字標籤、較大字體及 reduced motion。
- 暫停、速度、訊號、百科、淋巴結及返回戰場易找。百科／設定／匯入等遮住戰場的面板安全暫停；關閉後由玩家恢復，不自動開戰。
- 因果紀錄包含模擬時間、位置／對象、機制、前置狀態與結果，例如「已調理 → 攝入增加」「訊號不足 → 增援未往此處聚集」「過度發炎 → 組織損傷」。可篩選摘要，避免每一步刷屏；摘要不抹除重要因果。
- 百科完整可查，含細胞自主行為、病原差異、抗原與訊號作用、時間／群體抽象、來源，以及觀察到的失敗原因；關卡內可直接跳到對應條目。

## 13. 模組、內容與引擎契約

採 TypeScript＋Vite＋React。React 負責應用與介面；遊戲展示可選 PixiJS／Phaser、Three.js 或合適的分層 2.5D 方案，**不以使用 3D 引擎作為畫質達標證據**。依簡單功能樣板、可替換性與手機效能選擇，不要求保留舊 `src/tactics` 入口或舊幾何模型。

| 邊界         | 責任                                                                              |
| ------------ | --------------------------------------------------------------------------------- |
| domain       | 狀態、單位／病原／抗原／訊號 ID、命令、事件及結果型別。                           |
| content      | 關卡、地形、初始配置、供應與成本、AI 參數、訊號定義、反應路徑、目標、百科與來源。 |
| engine       | 純模擬步進、指令驗證、感知／AI、路徑、作用、訊號、發炎、淋巴結與勝敗。            |
| application  | 時鐘、規劃佇列、暫停／速度、一次性提交、存讀協調。                                |
| presentation | 相機、圖像、選取、動畫、事件播放與降低動態；不得計算權威作用。                    |
| ui           | 響應式介面、訊息、百科、因果紀錄及淋巴結面板。                                    |
| persistence  | 版本化序列化、完整驗證、原子載入及舊檔保護。                                      |

規則引擎不依賴 DOM、React、localStorage、動畫時鐘或全域 `Math.random()`；使用明確的 RNG 狀態。對同一種子、內容版本、帶模擬步號的指令序列與固定步數，所有播放速度／視覺設定應產生相同權威狀態及規則事件。

- 自主 AI 依權威狀態產生命令／意圖；渲染插值與膜形變不能改目標距離。
- 內容用穩定 ID、型別與載入驗證，不為每關寫一個巨大 UI／引擎條件分支。新增沿用既有機制的配置應主要改內容資料；新機制才擴充相應系統與契約。
- 模擬步內順序明確且可測，例如指令提交 → 場／狀態更新 → AI／移動 → 作用與來源更新 → 損傷／目標評估 → 有序事件。實際順序記錄於程式與測試，明定同一步勝敗衝突優先序。
- 事件具唯一 ID、步號、行為者／目標與機制結果。重播、讀檔或 React 重繪不可重放消耗；展示播放位置與權威存檔分離。
- 空間索引、低頻 AI／場更新、路徑快取、群體代表與視覺 LOD 控制成本；4× 負載過高可降低畫面更新或讓真實速度顯示受限，不能跳規則步或靜默改數值。

### 13.1 供後續美術替換的契約

## 16. M1 必要驗收

### 規則與內容

- 合法／非法／重複指令、資源保留／撤銷／提交、募集供應／內皮條件／延遲與交通一致，不重複扣點。
- AI 沒有逐個手動下令仍能偵測、移動、吞噬及釋放相關訊號；指定優先目標與恢復自主可用，無持續抖動／卡死。
- 訊號來源／擴散／衰減與趨化具因果；關掉對應來源或改變梯度會改變合理行為，訊號本身不直接傷害。

- 淋巴結抗原、成熟／遷移、活化／分化、交通與效果皆有實際狀態／延遲；初次反應不立即生效。先天與淋巴結兩條策略均需實際可行。
- 病原與過度發炎的損傷原因分開；抑制反應有防禦代價。目標、失敗、星等、同一步優先序及非負負荷一致。
- 同種子／指令／步數在 1×／2×／4×、正常／略過／降低動態下狀態與規則事件一致。暫停、背景切換、續玩與匯入不增加生理時間或重複作用。
- 用一個不同初始配置／訊號參數的測試關卡驗證資料擴充，不透過修改 M1 專屬引擎分支湊過。M2 的胞內與其他後續機制在各自開發時另驗，不能列為已完成。

### 畫面、操作與證據

- 桌面與直向手機完整操作：選關 → 指揮／暫停／速度 → 訊號 → 募集／調度 → 淋巴結 → 百科 → 勝敗／紀錄 → 續玩／匯入匯出。手機至少測 360 CSS px，說明模擬裝置或實體裝置。
- 實際拖曳測試第 4.2 節正反方向、縮放、點選不誤下令，包含觸控；若旋轉則測旋轉後方向與拾取。
- 第一階段檢查簡單佔位模型的角色／狀態辨識、命中對位及可替換契約，不以精緻 C 形體／材質作為玩法交付門檻；成品與報告標示佔位。全部核心動作仍可辨識，沒有只靠通用閃光代替吞噬。最終 C 外觀在後續美術替換階段另驗收。
- 留下桌面／手機截圖與短錄影，含至少待機、正常移動、抓取式地圖拖曳、調理、包覆吞入、募集到場／趨化、訊號視圖、淋巴結支援及結算。清除／胞內存活可另用受控場景錄製並標示；靜態圖不證明動畫完成。
- 檢查 UI 溢出、可點選大小、重疊選取、較大文字、鍵盤焦點、降低動態、錯誤訊息、資產 404 與 console 錯誤。
- 記錄瀏覽器、viewport、GPU／軟體繪圖、模擬群組數、1×／4× 的觀察效能。建議目標為常見桌面 60 FPS、手機 30 FPS；須列實測環境與限制，不能用 headless 軟體渲染宣稱實體手機流暢。

日後 M2–M6 完成時各自驗證特有機制；M3 殘存感染的控制勝利及 M6 有限結束／揭露／無一般星等必須另外測。第一階段不虛報六關已完成。

## 17. 下一個 AI 的製作順序

1. 確認 repo、環境與現行文件，實際檢視 C 圖；將舊原型列為參考，不繼承區域名額或既有模型的品質結論。
2. 用簡單幾何建立可操作樣板：一片組織、可分辨的巨噬／嗜中性／DC 與雙球菌、必要待機／移動／調理／包覆吞入；先建立可替換 manifest／provider、錨點與動作預覽，再直接推進玩法。同步驗證正向拖曳及手機選取，不等待精雕模型。
3. 建立純模擬契約、固定步進、AI、病原繁殖／擴散、訊號與內皮／募集、組織發炎，先確認自主反應可形成循環。
4. 加入混合指揮、暫停規劃／撤銷、1×／2×／4×，串接淋巴結支援、完整 M1 目標與勝敗。保留數據與可重現策略，調整平衡。
5. 完成百科、提示、因果紀錄、星等、存檔與匯入匯出、功能完整的簡化動畫與桌面／手機介面；依第 16 節修正並保留證據。
6. 完成 Pages 子路徑與發布驗證，交付可玩佔位版 M1、啟動方式、實際通過項、證據與限制，以及供後續美術 agent 使用的素材／動作契約、預覽與替換範例。美術由使用者另行指派；其他五關依後續任務擴充。

不需在每個一般技術選擇重新徵求確認；遇到實際衝突才提出具體問題。第一個 M1 不是單純 UI 或空流程面板；規則、AI、訊號、操作與動作都必須成立。

## 18. 範圍、決策紀錄與現況

2026-10-17 使用者要求：規格先改成混合型可暫停 RTS，另開 AI 重建；保留 C 風格但改善醜陋的現有 3D 形體；修正地圖拖曳反向；移除同區單位上限。本版將上述要求、先前 RTS 提案及原六關必要限制整合為單一規格，未更動程式與公開版本。

同日後續補充：使用者決定先做簡單、可替換模型，之後另派一個 agent 製作美術。因此第一階段以可玩佔位版 M1 為目標，最終 C 精修延後且不阻擋交付；必要動作與素材替換架構仍在第一階段完成。這是製作分工的最新決策，優先於先精修模型的舊安排。

渲染工具、場解析度、資源成本、募集與適應性延遲、節奏、星等閾值、聚合數與效能預算屬待切片驗證的工程／平衡值。不能把這些未驗證值稱為玩家已試玩認可。

最終產品範圍為六關單人遊戲、百科、自由選關、局內策略、紀錄、存檔與雙平台操作。多人、帳號／雲端同步、玩家 MOD、完整寄生蟲或其他疾病篇章不包含在本次重建。

## 19. 機制來源與適用範圍

以下保留已收錄的機制依據，不代表已完成整體專業審查，也不表示每個新訊號的參數已由這些來源驗證。實作時將具體訊號／反應機制的來源連到內容與百科條目；遊戲用擴散、成本與時間值應另標為教學抽象。

- **B1**：[Janeway, B 細胞反應與分化](https://www.ncbi.nlm.nih.gov/sites/books/NBK27142/)。基礎教科書，含 T 細胞依賴與非依賴反應的範圍。
- **B2**：[Janeway, 免疫記憶](https://www.ncbi.nlm.nih.gov/sites/books/NBK27158/)。用於初始、效應、記憶與再遇的基本區分。
- **B3**：[肺炎鏈球菌莢膜、補體與吞噬原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2812187/)。支持莢膜、補體沉積與調理吞噬的關係。
- **B4**：[Janeway, 巨噬細胞活化、胞內清除及組織損傷](https://www.ncbi.nlm.nih.gov/sites/books/NBK27153/)，以及 [Gordon 等，2005，Salmonella 人體巨噬細胞實驗](https://pubmed.ncbi.nlm.nih.gov/15908373/)。不直接採用實驗時間作遊戲時鐘。
- **B5**：[Medical Microbiology, Immune Defenses](https://www.ncbi.nlm.nih.gov/books/NBK8423/)。支持病毒胞外與感染細胞目標、先天與適應性反應的基礎分工。
- **B7**：[口腔上皮 IL-17 訊號與抗真菌防禦原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5147498/)。限定口腔黏膜情境。
- **B8**：[真菌形態／大小與嗜中性球反應原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4236687/)，以及 [口腔 IL-17 相關防禦研究](https://www.nature.com/articles/mi201457)。不能把全部 Th17 保護簡化為募集嗜中性球。
- **B10**：[Janeway, 體液免疫反應](https://www.ncbi.nlm.nih.gov/books/NBK10752/)。調理、中和及後續效應的基本區分。
- **B11**：[Janeway, 胞內病原與免疫逃避](https://www.ncbi.nlm.nih.gov/books/NBK27176/)。胞內區室、逃逸與細胞間傳播需依病原分別建模。
- **B12**：[CDC：Inactive Tuberculosis](https://www.cdc.gov/tb/about/inactive-tuberculosis.html)、[CDC：結核臨床概述](https://www.cdc.gov/tb/hcp/clinical-overview/)。感染控制可能伴隨活菌存留，與滅菌／臨床治療分開。
- **B13**：[HIV.gov：What Are HIV and AIDS?](https://www.hiv.gov/hiv-basics/overview/about-hiv-and-aids/what-are-hiv-and-aids)、[NIH：HIV and AIDS Basics](https://hivinfo.nih.gov/understanding-hiv/fact-sheets/hiv-and-aids-basics)。HIV 是病毒，AIDS 是晚期疾病狀態；CD4 受損與機會性感染的背景。
- **B14**：[NIH：Latent HIV Reservoir](https://hivinfo.nih.gov/understanding-hiv/fact-sheets/what-latent-hiv-reservoir)、[NIH：Stages of HIV Infection](https://hivinfo.nih.gov/understanding-hiv/fact-sheets/stages-hiv-infection)。潛伏感染、治療與病程時間，不能用短關卡清除判定代表治癒。
- **B15**：[NIH：HIV Life Cycle](https://hivinfo.nih.gov/understanding-hiv/fact-sheets/hiv-life-cycle)、[細胞靶向教科書](https://www.ncbi.nlm.nih.gov/books/NBK26926/)、[NIH：Opportunistic Infections](https://hivinfo.nih.gov/understanding-hiv/fact-sheets/what-opportunistic-infection)。宿主條件、CD4 受損及機會性感染的範圍。
- **B16**：[Janeway：HIV 的免疫控制](https://www.ncbi.nlm.nih.gov/books/NBK27126/)。抗病毒 T 細胞反應的控制效益；清除感染 CD4 的局部代價不代表 CD8 整體必定有害。
