## 可以從截圖確認的特徵

1. 組織地形具有透視、起伏、場景深度與接觸陰影。
2. 病原以成群、密集、佔據空間的形象出現，感染壓力在場景中可見。
3. 免疫角色位於同一場景中，吞噬近景呈現身體與目標的接觸關係。
4. 戰場佔主要視野，教學板也置於場景脈絡中。
5. 角色採高度擬人／怪獸化的表現，包含眼睛與嘴；此點與先前 C 規格的細胞形態限制不同，不能自動視為使用者已採用所有細節。

截圖無法充分確認即時／回合規則、鏡頭操作、尋路、技能派送方式或手機體驗，不以推測描述為已驗證功能。

## 當時首版 M1 的差異與影響（歷史觀察）

| 面向     | 目前 M1                          | 可探索的改版                                           |
| -------- | -------------------------------- | ------------------------------------------------------ |
| 戰場     | 三個獨立區域膜與標準化錨點       | 連續組織地形、可讀的入口／連線／感染灶                 |
| 病原壓力 | 每群一個圖示加負荷數字           | 依負荷及狀態呈現菌群密度與擴張，顯示數量有明確抽象上限 |
| 操作     | 選取後移到側欄／下方面板下指令   | 戰場內目標選取、就地常用指令、詳細機制按需展開         |
| 行動表演 | 依事件在區域內播放獨立 clip      | 連續的接近、接觸、包覆、退回或轉往下一目標             |
| 空間決策 | 邏輯位置是區域，區內錨點只供展示 | 是否讓區內位置、距離或路徑影響規則，取決於玩法改版範圍 |
| 資訊層級 | 同屏多個資源／說明／預告面板     | 戰場優先，必要資源常駐，條件與紀錄按需查閱             |

## 當時提出的製作範圍（已由 v2.0 整合取代）

先製作可直接操作的小型 M1 戰場切片，驗證：

- 同一片組織中的巨噬細胞、病原群落與增援入口。
- 點選單位、指定合法目標、就地回饋與取消操作。
- 接近 → 接觸 → 偽足包覆 → 吞入 → 正確結果的連續表演。
- 感染群落的密度、已調理外觀及清除後空間變化。
- 桌面與直向手機中，主要動作能在視野內被操作及看見。

規則層既有的生物機制、確定性事件與存檔邊界可供沿用；若改成新的時間或位置規則，應修改其權威模型，而非只在動畫層新增會影響勝敗的邏輯。

## 使用者後續選擇

曾提出三個範圍，使用者已選擇第 1 項：

1. 畫面、操作和玩法一起重做。
2. 先改戰場與操作，保留回合制／AP。
3. 主要提升細胞和動畫的立體感。

依此選擇進行新版可暫停即時戰術 M1 的實作、驗證與發布。美術將製作本專案自己的角色與組織資產，參考場景構成及動作可讀性，不直接使用 ImmuneQuest 截圖或角色素材。
