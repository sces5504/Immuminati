# 病原名稱與輕量細胞避讓（2026-10-18）

選取胞外病原時，指揮列主標題顯示各關的正式病原名稱；副標題保留防區、胞外位置與感染負荷。病毒也使用「胞外病原」，不再一律稱菌群。

`presentation/cellLayout.ts` 在展示層分散免疫細胞，不修改權威位置、攻擊／辨識距離、手動路徑、T–B 協作、RNG 或存檔。沒有新規則或存檔格式，舊局／undo 原樣保留。這是可讀性避讓，並非新增完整物理碰撞。

- 每次權威 state 變更才計算一次；暫停時只做既有平滑插值，不反覆搜尋。
- 優先保留原位置，再試前次附近位置與兩圈固定候選；位移最多5.4世界單位。偏移必須在可行走組織／通道內。
- 使用6單位空間桶；每單位最多26候選、每候選9桶、每桶8鄰居，固定工作量、總體 O(n)。飽和桶視為佔用，不掃描桶內所有人；這不是全場／同區單位名額限制。
- 找不到空位時保留單位，允許部分重疊；不以無限搜尋、強制擠走或縮小模型換取完全分離。
- 模型、世界標籤、模型點選、選取圈、路徑起點、圍堵環、吞噬／細胞毒／T–B 對接動畫來源對齊實際展示位置。權威事件與扣資源仍由引擎決定。
- 美術接手若改模型尺寸，請一併調整 `bodyRadius` 與桶寬（桶寬必須大於最大直徑），保持固定搜尋預算。
