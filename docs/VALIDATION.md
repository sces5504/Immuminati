## 規則與模組驗證

1. 非法指令保持原狀態、零事件、零扣點：同區移動、跨區吞噬、不可招募細胞、未知目標。
2. 調理不減少病原負荷；主動吞噬消耗同單位的主要作用，回合末不重複作用。
3. 增援預留容量不可超訂，一／兩次結算到場，到場不參與已結束的細胞階段。
4. 調度不占主要作用；等待推進與標記到期順序正確。
5. 細胞 → 病原 → 組織 → 等待／結果的固定順序；必要組織失守優先判敗。
6. 相同種子及指令序列完全重現。三個配置各以增援與調度兩種策略通關（6 條策略驗證）。
7. 85／84／60／59% 邊界星等、失守零星；100 組合法指令情境保持 AP、負荷與容量不變條件。
8. 新增抽象 sample 內容而不改引擎，驗證吞入囊泡後存活、宿主 ID、胞內增長與不誤判感染已清除。此為契約測試，不是 M2 完成。
9. 存讀及撤銷恢復 AP、容量、亂數、狀態與事件；已提交回合無法撤銷。
10. 版本、大小、格式、未知 ID、非法區域及狀態／撤銷快照不一致的存檔拒絕匯入。
11. 正常／4×／跳過／降低動態的播放器得到同結果，跳過只完成一次，取消清理計時器。
12. 內容連線、初始單位、百科與機制來源引用檢查通過。

## 真實介面操作

桌面與手機模擬均從首頁選關，經 UI 招募、調理、回合結算、主動吞噬、調度與最終結算，得到第 3 回合、87% 保全、三星；不是注入勝利狀態後拍照。

- 主操作命中框 ≥44×44 CSS px、360px 無水平溢出；手機實際執行觸控選取。
- 不操作 1.3 秒後，整體漂浮及局部膜 transform 均改變，各單位相位不同（−0.73／−1.46／−2.19 秒），權威存檔完全不變。
- 百科中英文／關鍵字搜尋、返回同局、設定與淋巴結支援說明可用；完成九角色／六病原及相關機制的可查條目。
- 正常、4×、跳過、系統降低動態、以合成 visibilitychange 模擬隱藏頁籤，對相同 UI 指令得到逐欄位相同的權威狀態及事件紀錄。
- 播放中追加點擊不重複作用；動畫中重新載入直接使用已提交狀態、不再扣 AP。
- 續玩後撤銷、下載存檔再匯入、拒絕損壞匯入且保持舊存檔、Storage quota 失敗仍可操作並提示匯出。
- 兩種版型全程 pageerror 0、HTTP 4xx／5xx 0。
- 六張卡片均可查閱；其他五關如實標記開發中。HIV 入口沒有必敗、特殊模式或空星槽等劇透。

開發中曾發現手機隱藏文字造成百科按鈕缺少可辨識名稱，以及測試的 Th1／Th17、因果紀錄選擇器不夠精確。已修正 accessible name 及測試定位，完整瀏覽器腳本最終通過。不是把測試失敗忽略或改成無條件通過。

## 效能觀察

`PLAYWRIGHT_BROWSERS_PATH=… node scripts/performance.mjs` 在獨立瀏覽器、沒有錄影及其他驗證同時執行時，量測 3 個細胞、3 個胞外群體、最多 1 個前景 clip，各狀態 2 秒 requestAnimationFrame 回呼間距：

| 情境               | 中位數  | p95     | 平均     |
| ------------------ | ------- | ------- | -------- |
| 桌面待機           | 16.7 ms | 16.8 ms | 17.26 ms |
| 桌面吞噬／清除     | 16.7 ms | 16.8 ms | 17.53 ms |
| 手機模擬待機       | 16.7 ms | 16.7 ms | 16.81 ms |
| 手機模擬吞噬／清除 | 16.7 ms | 16.8 ms | 16.67 ms |

原始資料及方法在 `evidence/performance.json`。這是 headless RAF 回呼節奏，不等於實體手機 GPU 的畫面呈現率。先前同時執行多個錄影瀏覽器時曾有較大延遲，已停止競爭工作再量測；不能以此宣稱所有手機均穩定 60 fps。
