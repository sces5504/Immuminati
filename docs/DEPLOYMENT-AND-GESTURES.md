# v3.1：玩家開局部署、雙指縮放與美術交接

日期：2026-10-18 UTC。延續 `7ca0b15`，保留原立體戰術 UI／操作及 C 柔光微觀立體。使用者附件三圖（10:02／10:34／10:40）已於本對話實際查看；紅圈移除略過動畫，紫圈首頁改為「運用免疫知識 · 直觀看見結果」，藍圈支援雙指縮放。

## 玩法變更

六關新局先進入開局部署，時間停在0。沒有預配可指揮隊伍；M3 保留一個感染巨噬宿主及其活菌，不能用撤下刪除感染，M6 既存宿主／病毒狀態也保留。每局有12部署點，與戰場5反應資源／6補體支援分開，不轉換、不再生；這是初始預算，不是同區／全場單位名額。開戰後仍靠原成本及等待募集。

每關兩個知識套組，寫明病原／所在區室、細胞適合原因與後續缺口。選套組是玩家的明確選擇，不會直接開始時間；可自行增減細胞與選起始防區。部署不自動給效應資格、抗體或分化；至少自選一個細胞才能確認，確認後仍暫停。可保存草稿回主頁／續玩；確認是不可撤銷的階段切換，避免戰鬥指令 undo 回到已退款部署。

規則3.1／內容campaign.2；schema2不變。3.0及更舊 active state／undo 原樣遷移，**不把舊局清隊或送回部署**。首次覆寫備份 `immuminati:tactics:pre-3.1`，匯入舊原文另存時間戳備份；歷史key／pre-3.0等不刪。準備階段有獨立嚴格驗證：預算守恆、固定宿主、時間／資源、無預先活化、state／undo同步。

## 操作與模型邊界

戰場移除「略過動畫」按鈕；底層動畫工具仍可供開發演練，降低動態設定保留。首頁事實列換成學習與可觀察結果的正向文字，沒有引入永久升級。

雙指相距變大放大、變小縮小，採原0.75–1.7範圍，以雙指中點投影維持抓取位置，沿用原平移邊界。手勢只接管戰場，頁面與對話框保持原瀏覽器操作；±／旋轉／重設保留作無障礙及桌面替代。記錄各pointer與capture，兩指／第三指、先放一指、cancel、lost capture及失焦分開處理；只剩一指時不接續發命令，全部離開後才開始新手勢。手勢不改權威位置、資源、選取或時間。單指抓取同向拖曳、標籤點選保留。

美術本輪未重做，交由 [美術建模交接 prompt](ART-HANDOFF-PROMPT.md)。模型／器官目前可玩且可替換，精細度仍待專業美術樣本驗收；不要把本輪部署UI改動說成美術已改善。
