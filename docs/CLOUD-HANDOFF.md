- 改成混合型 RTS：自主細胞＋可直接指揮關鍵單位＋隨時暫停，提供 1×／2×／4×。
- 玩法重心是協調免疫反應，不是每隻細胞都要點擊才吞噬。訊號影響趨化／狀態／環境，不是傷害法術。
- 連續組織戰場＋連動淋巴結流程面板；首次適應性反應比先天反應慢，有明示時間壓縮。
- **取消同區單位上限與容量預約；舊每區 3、全場 7 不沿用。** 募集靠供應、資源、內皮／到場程序及發炎代價平衡。
- 修正抓取式鏡頭：拖右時地形在螢幕上也向右，桌面與觸控一致。拖地圖放手不可誤下移動命令。
- 保留 C 柔光微觀立體，改善模型；現有球體拼裝、硬枝條、重複粉紅圓環不是合格基準。3D／2.5D 工具依樣板品質與手機效能選擇。
- 第一個重建里程碑是完整 M1 肺炎鏈球菌。六關題材、自由選關、無永久戰力、M3 控制感染與 M6 特殊有限結局依主規格保留；未完成關卡如實標示。
- 本機續玩／匯入匯出、百科、情境提示、因果紀錄、組織保全星等、桌面與直向手機、核心動作及 Pages `/Immuminati/` 均在 M1 交付範圍。

## 3. 開工順序與重要風險

先簡述實作計畫後直接實作、驗證、修正，持續完成 M1；一般技術選擇自行決定，不因每個工程選項停下等確認。

1. 確認 Git 狀態、環境、scripts、文件與圖；隔離舊原型規則。可參考既有純邏輯或工具，但不能只修改文案後宣稱 RTS 重建完成。
2. 先做小型動態美術樣板及正向地圖拖曳，檢查桌面／直向手機的細胞輪廓、膜、核、接觸與完整包覆吞入。美術缺項記錄後繼續可獨立工作；別把待改善素材標成已通過。
3. 建立獨立引擎與資料契約：固定步進、AI、連續空間、繁殖／擴散、訊號、內皮／募集、發炎與組織。沒有區域格位；密集視覺與效能用聚合處理。
4. 加入暫停規劃／撤銷、即時指揮、速度，串接抗原明確且有實際延遲的淋巴結支援。M1 早期補體／既存調理與新生特異性抗體分開，不讓普通莢膜多醣直接走泛用 DC→T→B 路徑。
5. 完成可重現 M1 策略、勝敗、星等、百科、提示、因果紀錄、存檔與所有核心動畫。新存檔不覆寫兩種舊 key；規則不依賴動畫回呼。
6. 跑修改相關的型別、內容、規則、建置、桌面／手機瀏覽器與 Pages 子路徑檢查，修正發現的問題並留下證據。

M1 自主反應、訊號視圖與淋巴結面板都要有真實引擎狀態，不能只做動畫流程。至少驗證兩種合法策略，且選擇真的改變感染／發炎／組織結果。

## 4. 驗證與交付紀錄

現有 `npm ci`、`npm run dev`、`npm run verify`、`npm run test:browser`、`npm run test:animation` 等只反映目前 package.json；重建時更新測試與腳本，使其驗證新行為。不能為保住舊測試，把被移除的區域容量做回來。

依 [主規格第 16 節](Immuminati-spec.md#16-m1-必要驗收) 留下實際結果，特別包括：

- 自主 AI、訊號因果、募集／跨內皮、淋巴結延遲、特異性及發炎取捨。
- 超過舊區域／全場限制的合法調度與募集，以及同一熱區密集群組壓力案例；技術預算不轉成區域上限。
- 1×／2×／4×、暫停、略過及降低動態對相同步數結算一致，沒有重複作用／扣點。
- 桌面與 360 CSS px 直向觸控的完整操作、正向拖曳、重疊選取、存讀與匯入匯出。
- 待機、調度、正向地圖拖曳、調理、包覆吞入、募集／趨化、訊號、淋巴結與結算的短錄影；存活／清除分支如用受控場景需標示。
- 素材清單、佔位與缺項、來源／授權、效能環境與限制、資產路徑、建置／部署 commit 及公開網址。

新實作／驗證紀錄另建或明確分版；不覆寫舊數據讓它看似通過新規格。沒有實測的項目如實列出，不能把 headless 觸控模擬稱為實體手機已驗證。
