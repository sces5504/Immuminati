# Immuminati 雲端開發交接

日期：2026-10-17。玩法規格已確認，美術選定 C「柔光微觀立體」，待機與行動動畫為必要需求。本次交接提供文件與參考圖；實際遊戲、去背分層素材及動畫程式尚待製作。

## 開工前閱讀順序

1. 根目錄 [AGENTS.md](../AGENTS.md)。
2. [主規格 v1.1](Immuminati-spec.md)，包含六關、玩法、模組、存檔、勝敗與 HIV 敘事。
3. [C 美術與動畫製作規格](art-direction/C-art-and-animation.md)。
4. 實際檢視 [已選 C 參考圖](art-direction/c-soft-micro-3d.png)，確認桌面／手機、材質與角色；不能只憑文字自行換畫風。

所有必要文件與圖片都應從此 repo 取得，不依賴原作者電腦的絕對路徑、先前聊天記錄或舊 repo 的 AGENTS.md。

## 當前狀態與實作邊界

- 這是新 repo，尚無可執行的遊戲專案或已驗證的 package scripts。
- 採 TypeScript＋Vite＋React、獨立純規則引擎、資料驅動內容、事件式動畫及版本化本機存檔。
- 電腦與手機同等重要；手機直向、點按操作、主要目標至少 44×44 CSS px。
- 六關從開場即可選擇，百科全可查；沒有永久數值升級與裝備。
- C 參考圖是概念畫面，不能直接鋪成完整畫面加熱區，不能把「靜態切圖＋所有動作只冒數字」當作完成。
- 待機要有細胞各自漂浮、呼吸與局部生命感；行動須依機制有對應動畫，第一關就要交付。
- 首版用可動 2.5D 素材實現 C 的立體風格，無須先建立完整 3D 引擎。

## 第一個製作里程碑

先完成一個包含真實規則與 C 動態美術的 M1 肺炎鏈球菌關卡，再擴充六關。

1. 初始化專案與明確模組邊界，鎖定相容依賴；建立型別、內容驗證、規則測試及建置指令。
2. 先做小型動態場景，驗證獨立角色待機漂浮、選取、調度與吞噬；記錄哪些素材是佔位、哪些已達 C 品質。
3. 完成 M1 的合法指令、AP、區域容量、增援等待、調理／吞噬、組織損傷與勝敗。
4. 引擎產生有序事件；展示負責播放，不能在動畫回呼計算傷害或再次扣 AP。正常、加速、跳過、背景切換後的規則結果一致。
5. 接入百科、提示、回合因果紀錄、組織保全星等與本機續玩／匯入匯出。
6. 驗證桌面與 360 CSS px 手機；提交待機及實際動作的短錄影。
7. 建立 GitHub Pages 的 Actions 與子路徑資產驗證：目前 project base 為 `/Immuminati/`。不要把只在本機根目錄成功當作部署驗收。

M1 完成後，用最小 M2 情境驗證胞內病原與訊號／呈遞擴充，再依主規格實作其餘四關。所有內容開放的產品規則不代表開發中可以把未完成關卡顯示為可玩並宣稱六關已交付；開發狀態要如實顯示。

## 關卡摘要

| ID | 主題 | 必須保留的差異 |
| --- | --- | --- |
| M1 | 肺炎鏈球菌 | 調理與吞噬分開；案例說明既存特異性抗體。 |
| M2 | 沙門氏菌 | Typhimurium 教學情境；吞入不必然清除，胞內存活及 Th1 支援。 |
| M3 | 結核分枝桿菌 | 控制感染／限制擴散，不要求滅菌；達標後依組織損傷評星。 |
| M4 | 流感 A | 游離病毒與感染細胞分開處理。 |
| M5 | 白色念珠菌 | 口腔黏膜、上皮防禦、酵母／菌絲及相應 Th17 作用。 |

HIV 局部控制可有用，不能靠最後回合無條件殺死全部細胞；沒有一般勝利或通關星。結局需說明受限案例與現代治療，細節以主規格為準。

## 交付時留下的紀錄

- 實際可執行的安裝、開發、驗證與建置指令，依已建立的 package scripts 記錄。
- 已跑檢查及結果，區分未跑、未通過與通過。
- 素材 manifest、動畫事件映射、缺項與來源／製作方式。
- 桌面／手機操作與待機／行動短錄影；記錄效能環境，不能把雲端模擬說成真機已測。
- Pages 部署／子路徑驗證結果與仍未完成的項目。

## 可直接用作雲端開工訊息

請在 sces5504/Immuminati 依 AGENTS.md、docs/Immuminati-spec.md 及 docs/art-direction/C-art-and-animation.md 開始製作，先實際檢視已選定的 C 參考圖。先建立模組化架構，再完成具有真實規則與完整操作的 M1 肺炎鏈球菌關卡。美術必須採柔光微觀立體，細胞待機時微微漂浮並有局部生命感，調度、吞噬、調理、招募與回合結果有對應動畫。不要把整張預覽圖加熱區當成遊戲，也不要延後到六關完成才補動畫。規則、內容、展示與儲存分離，正常／加速／跳過動畫的結算一致。完成手機直向、百科、存檔、星等、必要驗證與短錄影，再依規格擴充其餘關卡。
