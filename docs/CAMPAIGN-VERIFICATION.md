## 測試方式與證據界線

`test:campaign` 操作正式建置；實體點選完成基本選取、移動／撤銷與面板，排程招募則透過原 UI 按鈕事件。Playwright 受控時鐘驅動正式 RAF 控制器，沒有直接呼叫引擎或注入勝利狀態。每關截圖與錄影含開場、指揮、作戰及結算；儲存最終權威局面。

`test:campaign-ui` 額外使用明示的「抗體庫存／清空當波」版面測試存檔，只用來驗證直接消耗、重複點擊、略過及溢出，不能作為通關證據。`test:animation` 使用明示開發 fixture 檢視包覆吞入、清除／持續存活、C3b 灑落及 Y 抗體移近；不能宣稱該 fixture 就是完整關卡。

不使用上一輪64項、舊影片或舊公開站檢查作為本輪已驗證證據。瀏覽器為 Chromium 桌面及行動觸控模擬，未在實體 iPhone Safari 或 Android GPU 上測試。模型為程序素材，未經專業美術最終精修；免疫數值、時間與病原群是教學抽象。
