本輪使用者實玩回報 TB 在巨噬內不增殖，並要求查修其他關卡、HIV 持續至組織耗盡、打磨體驗。最新授權優先於歷史美術輪「不改引擎」；使用者後續明確授權「這次要推到main」；透過 PR #3 合併 main 並發布正式 Pages，保留私人 Preview 作比較。不使用付費建模 API。

## 查核與修正

| 關卡 | 查核結論與本輪變更 |
|---|---|
| M1 肺炎鏈球菌 | 保留胞外繁殖、莢膜降低吞噬效率、C3b／Fc 調理及吞入後等待殺菌。補體／抗體不直接進入胞內、不把 C3b 當 MAC 殺菌。未發現需要改寫此主循環的問題。 |
| M2 沙門氏菌 | 原來只有每個吞入批次各自 +1，人口分批方式會影響複製。改為一個受感染宿主共用的時鐘，按宿主總活負荷增殖；IFN-γ 活化抑制並支持清除，失控宿主破裂時把活菌轉移回胞外，沒有憑空刪除／複製菌量。 |
| M3 結核 | 原來完全缺少胞內增殖。現在巨噬含菌囊泡的活菌會增殖、負荷失控導致宿主破裂、組織受損與再播散。TB 控制需要相符且近距離的活化 Th1 協作＋局部 IFN-γ，或已建立圍堵；不是單按 IFN-γ 就保證滅菌。原先「每個吞入批次至少留 2」改為受感染宿主總活菌的保留條件。勝利仍為穩定圍堵，並非清除全部病原。 |
| M4 流感 A | 保留核內複製材料、胞外不繁殖、IFN-I 降低感染與產量、MHC-I 配對／交叉呈遞。修正產毒宿主無限存活：感染建立→產毒週期→感染相關細胞死亡，停止原來源產毒，但先前釋出的胞外病毒仍在。DC 可從感染宿主／其殘骸取得材料，避免胞外顆粒先消失就永遠無法交叉呈遞。另修正同一步「支援取樣路徑」被「追胞外病原」覆蓋而原地往返的衝突；有專用支援目的地時，不再執行第二套追擊移動。死亡組織不再是易感新宿主。 |
| M5 念珠菌 | 保留酵母／長菌絲差異、接觸顆粒、IL-17／IL-22 經上皮作用。DC 對菌絲只攝入小量局部材料，不把受調理加成的大段菌絲當整個可吞物。這不是宣稱 DC 不能攝取任何菌絲片段。 |
| M6 HIV | 移除時間、CD4 數值與單一防區失守的結算；所有防區保全精確降到 0 才給無星等 `limited` 結果。任何潛伏宿主都有機會再活化，不再特殊保護第一顆；新的感染可進入潛伏。再活化同步更新抗原／壓力／MHC 狀態。產毒按宿主週期，不會在宿主死亡後繼續。移除與感染無關的固定功能障礙增量；失去 CD4 支援增加組織耗損，防守可延長存續。 |

`content/campaign.ts.lifecycle` 配置胞內週期／增幅／失控門檻及病毒感染建立／產毒週期／來源壽命；引擎在固定 0.2 秒步進提交結果與事件，動畫不扣點、不改存活或結算。原 UI、待機／吞入、雙指與拖曳、部署、無名額限制、暫停／2×與原模型回退保留。

## 體驗打磨

- 選取受感染巨噬會顯示病原名、囊泡活負荷、下一次增殖時間／抑制狀態；局部剖視顯示同一權威數量及風險說明，桿菌用桿形符號。
- 原任務展開區分胞外、待殺菌、囊泡存活，病毒區分感染建立、產毒及潛伏來源。HIV 顯示剩餘防區與持續防守目標。
- 原事件列現在也顯示胞內增殖、釋出與損傷，協作提示依六關機制提供行動理由；病毒教學的觀察步驟接受入侵／釋出／宿主殺傷，不要求做無關的吞噬。
- 囊泡內可見病原數隨負荷增加，新增時有局部展開／分離；最多六個小模型，代表群體負荷，不聲稱每個符號是一隻菌。降低動態不播放分離，權威負荷一致。每畫格先彙整 cargo，避免每顆細胞反覆遍歷所有吞入批次。
- 已失守防區的組織宿主停止存活／產毒。NK／CD8 清除感染宿主仍有宿主損失的組織代價；不是免費刪除病毒工廠。
- 指揮列說明可在容器內換行，手機選取說明提升可讀性，不增加擋住地圖的新常駐面板。另修正暫停按鈕 hover／觸控殘留 hover 變深後文字也深的對比問題，播放符號強制文字顯示；宿主死亡不一概標成凋亡。病毒剖視列出產毒週期／下一輪等待，明示感染來源數不是胞內病毒顆數。

## 查閱依據與教學邊界

查閱日期 2026-10-18。NIH HIV 與 Salmonella PubMed 頁面可讀；部分 NCBI/PMC 原文遇到驗證頁，只使用可讀摘要／檢索摘要，不宣稱閱讀全文。下列均可供接手者核對，數值與遊戲秒數不是來源的臨床定量。

- [NIH：HIV 潛伏庫](https://hivinfo.nih.gov/understanding-hiv/fact-sheets/what-latent-hiv-reservoir)：潛伏感染不主動產毒，能再活化；ART 可以有效控制 HIV。
- [NIH：HIV life cycle](https://hivinfo.nih.gov/understanding-hiv/fact-sheets/hiv-life-cycle)：CD4 宿主、逆轉錄／整合、組裝與出芽。
- [Salmonella-containing vacuole（NIAID／NIH review）](https://pubmed.ncbi.nlm.nih.gov/18304858/)：SCV 是存活及複製場所。
- [2025 原始研究：CD4 介導局部髓系反應限制 Mtb](https://pubmed.ncbi.nlm.nih.gov/40489538/)：CD4 對控制重要，但功能不限於單一 IFN-γ。
- [2025 原始研究：IFN-γ alone fails to restrict Mtb in human macrophages](https://pubmed.ncbi.nlm.nih.gov/40285696/)：特定人類單核來源／肺泡巨噬培養中，IFN-γ 不保證限制菌生長；因此遊戲採協作與圍堵，不把 IFN-γ 當萬能殺菌開關。
- [原始研究：granuloma 與早期擴張／播散](https://pmc.ncbi.nlm.nih.gov/articles/PMC3134310/)：肉芽腫不是保證無菌的密封罩。
- [Influenza replication／IFN／apoptosis](https://pubmed.ncbi.nlm.nih.gov/28805681/)：核內 vRNP 複製、胞膜組裝出芽及感染相關死亡。
- [Pneumococcal capsule／opsonophagocytosis](https://pubmed.ncbi.nlm.nih.gov/19948837/)；[mucosal Candida／IL-17](https://pmc.ncbi.nlm.nih.gov/articles/PMC5733685/)。

這是局部群體教學模型：複製速度／菌量／破裂門檻、病毒產毒週期與平均壽命均為可調的時間壓縮；不模擬每顆菌、全部巨噬亞群、所有細胞死亡路徑。TB 的囊泡是主要呈現區室，不否認 Mtb 可造成囊泡損傷及細胞質接觸。病毒胞外傳播仍採防區內遇到易感宿主的聚合模型，移動線是路徑示意，非分子擴散解算。HIV 易感宿主群與可指揮 helper 分開抽象，沒有全面逐顆感染所有可指揮 CD4。

**HIV 的 CD4 支援不足→整體組織耗損是本關的遊戲抽象，並非宣稱 HIV 直接感染所有基質或必然在短時間破壞全身；本關未模擬 ART、機會性感染或臨床年尺度。** 結局保留明確 ART 資訊。引擎不設定必定在某秒結束；沒有感染且沒有 CD4 支援損失的狀態不會自行累積功能障礙或固定耗損。正式 M6 開場已有感染／潛伏來源，需持續防守。

每步免疫／感染效果前及移動後，以當前位置同步細胞防區；下達遠處移動意圖不會把囊泡內損傷瞬移到目的地。暫停時既有指令與undo保留，開始推進才依實際位置計算。重複下達同一個尚在執行的攻擊指令不再重建路徑，避免把正在跨防區的單位反覆拉回出發防區中心。

## 啟動與尚存限制

`npm ci` 後 `npm run dev`，進入 `/Immuminati/`；本輪引擎預設即生效。最新授權合併main後，新美術預設啟用；`VITE_ART_PREVIEW=original npm run dev` 可作原模型診斷，標準 `npm run build` 保持Pages子路徑；獨立私人站用 `node scripts/build-art-preview.mjs` 的相對路徑建置。

本輪優先修正可信規則、因果回饋、移動穩定與手機剖視，不宣稱已完成商業發行認證。仍需真人策略／難度回饋、實體 iPhone Safari／Android GPU 與大量單位壓測。Vite 的 Three.js／預覽主包>500kB警告仍在，建置成功；沒有隱藏警告。微生物、器官、時間與CD4支援耗損的抽象邊界依上文，沒有新增付費Tripo生成或ART機制。
